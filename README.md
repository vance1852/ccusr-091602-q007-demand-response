# 制造用能削峰协同

把生产任务的功率需求与园区需量约束放在同一时间轴中。电网临时需量控制通知、
分时电价、设备功率曲线、工艺不可中断区间、恢复爬坡、启停与互锁约束均作为
版本化输入参与 15 分钟滚动计算；已执行的功率片段与进入保温阶段的任务不可改写。

## 运行

```bash
python3 -m unittest discover -s tests -v   # 24 项验收测试
python3 demo.py                            # 跨 9 个计费窗口的端到端演示
```

## 领域划分

| 模块 | 职责 |
| --- | --- |
| `app/timegrid.py` | 15 分钟槽位、UTC+8 时区对齐 |
| `app/models.py` | 分时电价、计费窗口、设备/任务功率曲线、电网通知（契约内 4 种负荷类型） |
| `app/plan.py` | 不可变计划版本：逐任务功率、峰值归因、牺牲、违例、保护冲突、窗口账目、版本 diff |
| `app/repository.py` | JSON 持久化仓库、模拟时钟、有期限保护、冻结实测、窗口关闭快照 |
| `app/scheduler.py` | 滚动重算引擎：移峰块 / 中断-恢复 / 尾部削减贪心 + 约束校验 |
| `app/service.py` | 协同服务：通知幂等合并、审批、保护、仲裁、时钟推进、查询 |
| `app/scenario.py` | 验收场景（热处理炉、互锁空压机、压铸线、爬坡风机、基础负荷） |

## 关键语义

- **不可变**：`now` 之前槽位取自冻结实测，任何修订不得改写；改写直接抛
  `PermissionError`。保温任务（`holding_from`）只按保温功率延续到最迟完工；
  工艺不可中断区间、现场强制运行、`must_run` 均锁定。
- **可移峰**：`shiftable` 整块平移，受最迟完工与设备互锁组约束，按电费增量
  与完工延迟选落点；`interruptible`/`ramping` 可中断-恢复，受最少运行、
  启停次数上限、恢复爬坡时长约束；运行段末端停机记为尾部削减（`curtail`），
  不占用重启次数。
- **一次决策**：相同 `notice_key` + 相同窗口/限值的重试（含不同 `retry_seq`）
  只并入当前版本的 `merged_retry_seqs`，不产生新版本；参数变化才触发新决策。
- **可比较的版本**：每个计划不可变，`diff` 列出逐任务变化、与上一版峰值差；
  `peaks` 给出每个窗口峰值来自哪些任务，`sacrifices` 说明削减/移峰牺牲的
  电量、完工延迟与恢复爬坡代价。
- **审批与仲裁**：能源主管批准（`calculated → approved`，首次落地执行后
  转 `active`）；生产经理可对单任务提出有期限保护；保护与削峰冲突时计划进入
  `awaiting_arbitration`，仲裁结论取契约三种结果之一，存在硬违例的计划不可批准。
- **滚动账目**：计费窗口在时钟跨过其结束时刻关闭，关闭瞬间快照执行版本的
  计划需量与费用；之后查询中的计划值永远是该快照，实际值独立来自冻结实测，
  二者差额、需量电费与超约罚金分列。
- **重启安全**：仓库 JSON 原子写入；重启后恢复时钟、实测、保护仲裁记录与
  全部计划版本，重算只影响未来槽位。

`domain_contract.json` 约定计划状态、负荷类型和仲裁结论。功率单位为 kW，
能量单位为 kWh，计费窗口带明确时区与起止边界。
